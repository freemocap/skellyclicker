# Archived previous application

This directory preserves the previous SkellyClicker application as reference. The original README and source are retained. The current application lives in ../backend and ../skellyclicker-ui and does not import this directory.

The archive includes the working-tree state at the time of the move, including local edits to the old lockfile and IDE configuration. The legacy local .venv was preserved on disk but is ignored by Git; virtual environments contain absolute paths, so relocation does not promise it remains executable. Nothing was deleted.
