# Quality ranking and bulk image selection

Generate training data places selection/generation controls on the left and a bounded image gallery on the right. Select best images previews a deterministic ranking of current dataset members. It does not change membership. Apply keeps the exact proposed camera-image IDs in one immutable review revision. Remove checked uses one bulk request. Previously excluded images do not return during ranking; restoration is an explicit operation. Original images, labels, videos and prior training snapshots remain unchanged.

## Source measurements and defaults

The measurements come from the prepared candidate bundle and generated labels, not DLC prediction confidence or a new pose evaluation. The current recording adapter saved silhouette overlap (IoU), recording-mask coverage, shared valid depth coverage, common depth pixels and median absolute rendered/measured depth disagreement in millimetres. The label table supplies valid, in-bounds keypoint fraction. Right-camera mask selection is pose-conditioned; the current mask preset is recording-specific. These measurements can reject obvious failures but cannot establish label correctness.

Quality score is a chosen heuristic, not a calibrated probability: 100 times the weighted mean of camera IoU, camera mask fraction, depth coverage, exp(-depth_error_mm / 5 mm), and in-bounds fraction. Default weights are all one. Five millimetres is a normalization choice from the existing pilot depth gate, not a claim about camera accuracy. Each weight is configurable; at least one must be positive. Missing enabled score factors produce an unknown score, never zero or an invented confident value.

Default floors: original source fit passed, camera IoU >=0.72, mask fraction >=0.8, depth coverage >=0.5, common depth >=100 pixels, depth error <=5 mm, in-bounds fraction >=0.9. Original-fit acceptance is a separate switch: while enabled it additionally enforces the saved worker decision (left IoU >=0.78, right >=0.72, both mask fractions >=0.8, common depth >=100, coverage >=0.5, depth error <5 mm). Turn that switch off to evaluate independently relaxed factor thresholds. Missing required gate measurements are ineligible. The preview returns fewer than N images if fewer qualify; it never relaxes gates to fill the quota.

Ties sort by source frame, camera and stable image ID. Optional temporal spacing applies separately per camera, allowing both images of a stereo moment while limiting adjacent duplicates. N counts camera images, not stereo pairs. Existing moment IDs remain intact for training splits. Temporal spacing is a sampling constraint, not an additional quality claim.

## Persistence and caching

Both preview and bulk mutation bind label and selection hashes. A changed selection produces HTTP409, requiring a new preview. Preview identifiers bind policy, source pose hash and exact selected IDs; applying a ranking checks that identifier and retains its full provenance in the review manifest. Preview tokens are bounded in server memory; restarting the backend requires previewing again. Atomic project-pointer publication occurs only after the immutable selection is written. A failed commit leaves active membership unchanged. No-op selection requests create no revision.

Thumbnail preparation caches verified immutable label/geometry inputs independently of selection revision. File size/mtime/ctime changes invalidate the preparation cache and trigger content checks. Individual image changes also invalidate image rendering. The first full projection index still needs to be read; this cache does not remove that cold-start cost.

## Verification

`backend/tests/test_quality.py` covers score ordering, unknowns, temporal spacing, independent original-fit gating, stale preview rejection, failed publication, explicit restoration, cached-thumbnail invalidation and bulk selection of a 3,038-image/157,976-label fixture. Existing labels and previous review revisions remain byte-identical. In a local run, remove100 took46ms and keep100 took39ms. Real read-only warm thumbnail calls fell from194–243ms to9ms for cached images and53ms for newly rendered images; cold projection preparation remained39–46seconds. These are local measurements, not performance guarantees.

Read-only inspection of the reported recording found768 eligible images among3007 current members, with389 unknown scores. Screenshot frames67–71 failed the gates while63 and72 passed. Membership was not changed to obtain these results; counts can change as the human continues review.

## Object-relative viewpoint coverage

Default selection is Quality + viewpoint diversity; Quality only remains selectable. Both apply the configured quality gates first. Diverse selection uses one priority queue per occupied spherical cell, preferring the least represented available cell and then the highest score, source frame, camera and image ID. All available cells receive their first image before a cell receives its second, subject to optional temporal spacing. This is deterministic greedy balancing, not a claim of globally optimal sampling with spacing constraints. Sparse cells are not fabricated and fewer than N images can be returned.

The saved transform maps original STL coordinates in metres into the named camera frame. For T_camera_from_stl=[R,t], the camera centre in STL coordinates is -R-transpose*t. Subtract the STL bounding-box centre (converted from authored mm or m into metres), then normalize. Left and right use their respective calibrated saved transforms. This does not use the FoundationPose centred-model transform, Euler angles, DLC predictions or a new pose solve. Original STL axes are preserved; no anatomical/Blender conversion is inserted. Nonfinite, nonrigid, reflected, missing or zero-distance transforms are unknown. Failed source fits are not counted as reliable coverage unless the user explicitly relaxes the original-fit gate and the individual quality gates qualify them.

The grid divides z=cos(polar angle) uniformly into six bands and azimuth atan2(y,x) into twelve sectors by default. A spherical strip has area d(phi)*d(z), so every cell has solid angle4*pi/(6*12). Bins are indexed z_index*azimuth_bins+azimuth_index; exact poles use azimuth0 deterministically. Resolution is inspectable and configurable (azimuth4–36, z2–18). Changing resolution changes the sampling policy and requires a new preview. The committed ranking provenance includes the grid, centre, source hash and exact selected IDs.

The coverage response separates current members, quality-eligible pool and proposed subset. Each pool reports counts, known directions, unknown/unreliable viewpoints, occupied cells and samples. Quality-score unknown counts remain separate from viewpoint unknown counts. Renderer orbit changes only the display, never these object-frame bins or the selected IDs. A cold preview of the actual recording found768 eligible images in35 of72 cells: quality-only100 covered18 cells, diversity100 covered35. The remaining37 cells are genuinely unrepresented by eligible source observations, not evidence of tracker failure in those directions.

`test_viewpoint_quality.py` verifies inverse rigid transforms, stereo baseline sign, non-origin centres, common-world rigid-transform invariance, metre/mm equivalence, invalid/reflected transforms, pole binning, equal-area indexing, count conservation and deterministic diversity before score. Source-fit accuracy remains a limitation; coverage is coverage of these recorded reference estimates.
